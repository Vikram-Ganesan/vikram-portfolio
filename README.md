## Run Locally

### Prerequisites

- Node.js, preferably the current LTS release
- npm

### Installation

```bash
git clone https://github.com/Vikram-Ganesan/vikram-portfolio.git
cd vikram-portfolio
npm install
```

### Start the development server

```bash
npm run dev
```

The Vite development server is configured to run at:

```text
http://localhost:3000
```

### Production build

```bash
npm run build
```

### Preview production build

```bash
npm run preview
```

### Formatting and validation

```bash
npm run format
npm run format:check
npm run lint
npm run build
npm run validate
```

The Husky pre-commit hook runs `npm run validate` and blocks a commit if formatting, lint, TypeScript, or production build checks fail. TypeScript/ESLint imports must preserve filename casing; component files use PascalCase, TypeScript utility files and source folders use kebab-case, and the Vite entry point remains `main.tsx`.
